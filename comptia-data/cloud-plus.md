# CompTIA Cloud+ (CV0-002 v4.0) — Terminology Inventory

## Domains and Percentage Weights
1. **1.0 Configuration and Deployment** — 24%
2. **2.0 Security** — 16%
3. **3.0 Maintenance** — 18%
4. **4.0 Management** — 20%
5. **5.0 Troubleshooting** — 22%

## 1.0 Configuration and Deployment
- Cloud models: public/private/hybrid/community; IaaS/PaaS/SaaS
- Network config: VPN, IDS/IPS, DMZ, VXLAN, network segmentation/microsegmentation
- Sizing: CPU/RAM (bursting, ballooning, overcommitment, hyperthreading, VT-x)
- Storage: IOPS, NAS/DAS/SAN, object storage, thick/thin provisioning, deduplication/compression, storage tiers, ACLs, zoning
- Migration: P2V/V2V/V2P/P2P, virtualization format
- Identity: SSO, federation, DNS/DHCP/certificate services, MFA, IPS/IDS

## 2.0 Security
- Encryption: IPSec, SSL/TLS, PKI; tunneling (L2TP, PPTP, GRE)
- ACLs: RBAC, MAC/DAC, MFA, SSO
- Automation security: APIs, CLI, web GUI, orchestration, scripting; firewall, antivirus/anti-malware, IPS/IDS, HIPS

## 3.0 Maintenance
- Patching: hypervisors, VMs, virtual appliances, rolling update, blue-green deployment, failover cluster
- Updates: hotfix, patch, version update, rollback; runbook management, orchestration, snapshot/cloning
- Backup: snapshot/redirect-on-write, clone, full/differential/incremental, change block tracking
- DR: RPO/RTO, SLAs, site mirroring, replication, archiving
- BCP: alternate sites, continuity of operations, edge sites

## 4.0 Management
- Monitoring: baselines, anomalies, event correlation, forecasting
- Resource allocation: hybrid/community/public/private, elasticity, CMDB
- Provisioning: auto-scaling, cloud bursting, application lifecycle
- Account provisioning: federation, SSO, ACLs, lockout/password complexity
- Performance: scale up/down (vertical), scale in/out (horizontal)
- SLA metrics: chargeback/showback, uptime/downtime

## 5.0 Troubleshooting
- Deployment issues: workflow breakdowns, integration issues, resource contention, licensing
- Capacity: API request limits, bandwidth limitations, IP address limitations
- Connectivity tools: ping, tracert/traceroute, telnet, netstat, nslookup/dig, ipconfig/ifconfig, route, arp, ssh, tcpdump
- Security: authentication/authorization issues, certificate expiration, privilege escalation

## Key acronyms
IaaS, PaaS, SaaS, XaaS, CASB, CMDB, DRaaS, HSM, IAM, MFA, NFV, PKI, RBAC, RPO, RTO, SIEM, SLA, SSO, VDI, VPC, VPN, VXLAN, WAF, and the full standard cloud/IT acronym set.
