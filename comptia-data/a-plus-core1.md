## 1.0 Mobile Devices
- Laptop hardware: battery, keyboard/keys, RAM, HDD/SSD migration and replacement, wireless cards, biometrics, near-field scanner
- Display: LCD (IPS, TN, VA), OLED, WiFi antenna, camera/webcam, microphone, touch screen/digitizer, inverter
- Accessories/ports: USB/USB-C/microUSB/miniUSB, Lightning, serial interfaces, NFC, Bluetooth, hotspot, docking station, port replicator, trackpad
- Connectivity: 2G/3G/4G/5G, GSM vs. CDMA, PRL updates, Bluetooth pairing, location services, GPS, MDM/MAM, two-factor authentication, mobile sync (Microsoft 365, Google Workspace, iCloud — mail, photos, calendar, contacts)

## 2.0 Networking
- Ports/Protocols: FTP (20/21), SSH (22), Telnet (23), SMTP (25), DNS (53), DHCP (67/68), HTTP (80), POP3 (110), NetBIOS/NetBT (137/139), IMAP (143), SNMP (161/162), LDAP (389), HTTPS (443), SMB/CIFS (445), RDP (3389); TCP vs. UDP
- Hardware: routers, switches (managed/unmanaged), access points, patch panel, firewall, PoE (injectors/switch), hub, cable modem, DSL, ONT, NIC, SDN
- Wireless: 2.4GHz/5GHz, Bluetooth, 802.11 a/b/g/n/ac(WiFi5)/ax(WiFi6), NFC, RFID, long-range fixed wireless
- Services: DNS, DHCP, fileshare, print servers, mail servers, syslog, web servers, AAA, spam gateways, UTM, load balancers, proxy servers, SCADA, IoT
- IP addressing: IPv4 private/public, IPv6, APIPA, static/dynamic, gateway
- Config: DNS records (A, AAAA, MX, TXT — DKIM, SPF, DMARC), DHCP leases/reservations/scope, VLAN, VPN
- Internet connections: satellite, fiber, cable, DSL, cellular, WISP; network types LAN/WAN/PAN/MAN/SAN/WLAN
- Tools: crimper, cable stripper, WiFi analyzer, toner probe, punchdown tool, cable tester, loopback plug, network tap

## 3.0 Hardware
- Cables: Cat5/5e/6/6a, coaxial, STP/UTP, plenum, fiber, T568A/B; USB 2.0/3.0, serial, Thunderbolt; HDMI, DisplayPort, DVI, VGA; SATA, SCSI, eSATA, IDE; connectors RJ11, RJ45, F-type, ST, SC, LC, microUSB, miniUSB, USB-C, Molex, Lightning, DB9
- RAM: virtual RAM, SODIMM, DDR3/DDR4/DDR5, ECC, single/dual/triple/quad-channel
- Storage: HDD speeds (5400/7200/10000/15000 rpm), SSD (NVMe, SATA, PCIe, M.2, mSATA), RAID 0/1/5/10, flash drives, memory cards, optical drives
- Motherboards/CPU: ATX/ITX form factors, PCI/PCIe, SATA/eSATA headers, M.2, CPU sockets (AMD/Intel), BIOS/UEFI settings (Secure Boot, TPM, boot password), x64/x86, ARM, multicore/multithreading, expansion cards (sound, video, capture, NIC), cooling (fans, heat sink, thermal paste, liquid)
- Power supply: 110-120VAC vs 220-240VAC, output 3.3V/5V/12V, 20-pin to 24-pin adapter, redundant/modular PSU, wattage rating
- Printers: PCL vs PostScript, USB/Ethernet/wireless connectivity, print server, duplex/orientation/tray/quality settings, user authentication, audit logs, secured prints, network scan (email/SMB/cloud), ADF/flatbed scanner
- Printer consumables: laser (imaging drum, fuser, transfer belt/roller, pickup rollers), inkjet (ink cartridge, print head, carriage belt), thermal (feed assembly, heating element), impact (print head, ribbon, tractor feed), 3-D (filament, resin, print bed)

## 4.0 Virtualization and Cloud Computing
- Cloud models: private/public/hybrid/community, IaaS/SaaS/PaaS
- Cloud characteristics: shared resources, metered utilization, rapid elasticity, high availability, file sync
- Desktop virtualization: VDI on-premises/cloud
- Client-side virtualization: sandbox, test/dev, application virtualization (legacy software, cross-platform)

## 5.0 Hardware and Network Troubleshooting
- Methodology: identify problem, establish theory, test theory, plan of action, verify functionality, document
- Motherboard/RAM/CPU/power symptoms: POST beeps, BSOD/pinwheel, black screen, no power, sluggish performance, overheating, intermittent shutdown, capacitor swelling
- Storage/RAID symptoms: LED indicators, grinding/clicking, bootable device not found, data loss/corruption, RAID failure, S.M.A.R.T. failure, IOPS
- Display symptoms: incorrect data source, cabling, burned bulb, fuzzy image, burn-in, dead pixels
- Mobile symptoms: poor battery health, swollen battery, broken screen, liquid damage, digitizer issues
- Printer symptoms: lines on page, garbled print, toner not fusing, paper jams, faded print, speckling
- Network symptoms: intermittent wireless, slow speeds, jitter, poor VoIP quality, port flapping, high latency
