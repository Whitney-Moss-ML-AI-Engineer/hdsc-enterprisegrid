## Key terminology
- Statistics: t-tests, ANOVA, hypothesis testing, confidence intervals, R2, RMSE, ROC/AUC, Pearson/Spearman correlation, confusion matrix, precision/recall/F1
- Probability: normal/Poisson/binomial distributions, Monte Carlo simulation, Bayes' rule, bootstrapping
- Linear algebra: eigenvalues/eigenvectors, matrix decomposition, Euclidean/cosine distance
- Time series: AR/MA/ARIMA, survival analysis, A/B testing, RCTs
- EDA: scatter plots, box plots, heat maps, histograms
- Feature engineering: one-hot encoding, normalization, standardization, binning
- ML fundamentals: bias-variance tradeoff, cross-validation (k-fold), regularization, SMOTE, ensemble models, hyperparameter tuning
- Statistical ML: OLS/ridge/LASSO regression, logistic regression, Naive Bayes
- Tree-based ML: decision trees, random forest, gradient boosting/XGBoost, bagging
- Deep learning: neural networks (CNN, RNN, LSTM, GAN, Transformers), ReLU/sigmoid/softmax, PyTorch, TensorFlow/Keras, Adam optimizer
- Unsupervised ML: k-means, DBSCAN, PCA, t-SNE, UMAP, KNN
- Data ops: data formats (CSV, JSON, Parquet), CRISP-DM, version control, MLOps, CI/CD, model deployment/monitoring
- NLP: tokenization, TF-IDF, Word2vec, GloVe, sentiment analysis, NER, NLU/NLG
- Computer vision: OCR, object detection/segmentation, data augmentation
- Specialized: graph analysis, reinforcement learning, anomaly/fraud detection
