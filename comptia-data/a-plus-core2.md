## 1.0 Operating Systems
- Windows 10 editions: Home, Pro, Pro for Workstations, Enterprise; gpedit.msc, BitLocker, RDP, in-place upgrade
- Command-line tools: cd, dir, md, rmdir, ipconfig, ping, hostname, netstat, nslookup, chkdsk, net user, net use, tracert, format, xcopy, copy, robocopy, gpupdate, gpresult, shutdown, sfc, diskpart, pathping, winver
- Windows 10 tools: Task Manager (Services/Startup/Performance/Processes/Users); MMC snap-ins — Event Viewer (eventvwr.msc), Disk Management (diskmgmt.msc), Task Scheduler (taskschd.msc), Device Manager (devmgmt.msc), Certificate Manager (certmgr.msc), Local Users and Groups (lusrmgr.msc), Performance Monitor (perfmon.msc), Group Policy Editor (gpedit.msc); System Information (msinfo32.exe), Resource Monitor (resmon.exe), System Configuration (msconfig.exe), Disk Cleanup (cleanmgr.exe), Disk Defragment (dfrgui.exe), Registry Editor (regedit.exe)
- Control Panel utilities: Internet Options, Devices and Printers, Programs and Features, Network and Sharing Center, System, Windows Defender Firewall, Mail, Sound, User Accounts, Device Manager, Indexing Options, Administrative Tools, File Explorer Options, Power Options (Hibernate, power plans, sleep/standby, fast startup, USB selective suspend), Ease of Access
- Windows Settings: Time and Language, Update and Security, Personalization, Apps, Privacy, System, Devices, Network and Internet, Gaming, Accounts
- Networking features: workgroup vs. domain, local firewall, client network config (IP/DNS/subnet/gateway), VPN, wireless/wired/WWAN connections, proxy settings, public vs. private network, metered connections
- Application install concepts: 32-bit vs 64-bit, ISO mountable, physical media vs. downloadable
- OS types: Windows, Linux, macOS, Chrome OS, iPadOS, iOS, Android; filesystems NTFS, FAT32, ext3, ext4, APFS, exFAT
- Installation/upgrade: boot methods (USB, optical, network, external drive), upgrade/clean install/image deployment/repair install/remote network install, GPT/MBR partitioning
- macOS tools: .dmg/.pkg/.app, App Store, System Preferences, Multiple desktops, Mission Control, Keychain, Spotlight, iCloud, Finder, Disk Utility, FileVault, Terminal, Force Quit
- Linux commands: ls, pwd, mv, cp, rm, chmod, chown, su/sudo, apt-get, yum, ip, df, grep, ps, man, top, find, dig, cat, nano; Samba

## 2.0 Security
- Active Directory: login script, domain, Group Policy, organizational units, home folder, folder redirection, security groups; MDM
- Wireless security: WPA2, WPA3, TKIP, AES, RADIUS, TACACS+, Kerberos
- Malware defense tools: recovery mode, antivirus, anti-malware, software firewalls, anti-phishing training, OS reinstallation
- Windows security settings: Defender Antivirus, Firewall (port/application security), users/groups (standard/admin/guest/power user), login options (password, PIN, fingerprint, facial recognition, SSO), NTFS vs. share permissions, UAC, BitLocker, BitLocker To Go, EFS
- Workstation hardening: data-at-rest encryption, password complexity/expiration, BIOS/UEFI passwords, screensaver locks, account lockout, disable AutoRun/AutoPlay, change default admin account
- Mobile/embedded security: screen locks (facial, PIN, fingerprint, pattern, swipe), remote wipe, locator apps, device encryption, remote backup, BYOD vs. corporate-owned, IoT
- Data destruction: drilling, shredding, degaussing, incinerating, wiping, low-level/standard formatting, third-party certification of destruction
- SOHO network security: default password change, IP filtering, firmware updates, content filtering, DHCP reservations, static WAN IP, UPnP, screened subnet, SSID management, encryption settings, port forwarding
- Browser security: trusted/untrusted sources, hashing, password managers, valid certificates, pop-up blocker, clearing browsing data/cache, private browsing, ad blockers

## 3.0 Software Troubleshooting
- Windows OS symptoms/fixes: BSOD, sluggish performance, boot problems, services not starting, low memory warnings; reboot, restart services, system file check, repair Windows, restore, reimage, roll back updates
- Malware removal best practice: safe mode, preinstallation environment, update anti-malware, System Restore
- Mobile connectivity troubleshooting: Bluetooth, WiFi, NFC, AirDrop

## 4.0 Operational Procedures
- Documentation: ticketing systems, asset management (inventory, tags, procurement, warranty/licensing), AUP, network topology diagrams, regulatory compliance docs, SOPs, knowledge base
- Change management: rollback plan, sandbox testing, request forms, risk analysis, change board approval
- Backup/recovery: full, incremental, differential, synthetic; GFS rotation, 3-2-1 backup rule
- Safety: ESD straps/mats, equipment grounding, antistatic bags
- Environmental: MSDS, temperature/humidity, ventilation, surge suppressor, battery backup
- Licensing/privacy: chain of custody, DRM/EULA, PII, healthcare data, data retention
- Scripting: .bat, .ps1, .vbs, .sh, .js, .py — automation, remapping drives, app install, automated backups
- Remote access: RDP, VPN, VNC, SSH, RMM, MSRA, screen-sharing/video-conferencing/file-transfer software
