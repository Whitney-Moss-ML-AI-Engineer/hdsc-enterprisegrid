# CompTIA CySA+ (CS0-002) — Terminology Inventory

## Domains and Percentage Weights
1. **1.0 Threat and Vulnerability Management** — 22%
2. **2.0 Software and Systems Security** — 18%
3. **3.0 Security Operations and Monitoring** — 25%
4. **4.0 Incident Response** — 22%
5. **5.0 Compliance and Assessment** — 13%

## Key terminology
- Threat intelligence: OSINT, STIX, TAXII, MITRE ATT&CK, Diamond Model, Cyber Kill Chain, CVSS, ISACs
- Vulnerability management: credentialed/non-credentialed scanning, false positive/negative, compensating controls, patching/hardening
- Scanners: Nessus, OpenVAS, Qualys, OWASP ZAP, Burp Suite, Nikto, Nmap, Aircrack-ng
- Specialized tech: IoT, ICS/SCADA (Modbus), RTOS, SoC, FPGA
- Cloud threats: SaaS/PaaS/IaaS, FaaS/serverless, IaC, insecure API
- Infrastructure security: segmentation, VPC, VPN, CASB, honeypot, encryption, certificate management
- Software assurance: SDLC, DevSecOps, static/dynamic analysis, secure coding (input validation, parameterized queries), SAML/SOAP/REST, microservices
- Hardware assurance: TPM, HSM, UEFI, secure enclave, self-encrypting drives, measured boot
- Monitoring: SIEM, UEBA, DNS/flow/packet analysis, DKIM/DMARC/SPF email analysis
- Automation: SOAR, SCAP, CI/CD, machine learning
- Incident response: lifecycle (preparation, detection, containment, eradication, recovery, post-incident), IoCs (network/host/application), digital forensics (Wireshark, tcpdump, disk/memory/mobile/cloud forensics)
- Compliance: PII/PHI/SPI, DLP, data masking/tokenization, NIST, risk frameworks, red/blue/purple team exercises
