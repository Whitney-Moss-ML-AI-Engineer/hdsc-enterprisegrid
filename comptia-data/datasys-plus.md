## Key terminology
- Database types: relational vs. non-relational, NoSQL (document, key-value, column-oriented, graph); named products DynamoDB, Cosmos DB, Cassandra, MongoDB, Neo4j
- SQL: DDL/DML, ACID principles, triggers, stored procedures, functions, views
- Scripting: PowerShell, Python, Linux/Windows CLI
- ORM: Hibernate, Entity Framework
- Deployment: PaaS/SaaS/IaaS, logical/physical schema, data dictionary, ERD
- Connectivity: DNS, client/server architecture, firewall, static/dynamic IP
- Testing: stress testing, regression testing, referential integrity validation, scalability validation
- Monitoring: resource utilization (CPU/memory/disk), deadlock monitoring, transaction/system logs
- Maintenance: query/index optimization, patch management, load balancing, capacity planning
- Documentation: ERD, UML editors
- Security: encryption (in-transit, at-rest), data masking, PII/PHI, PCI DSS, GDPR, least privilege, service accounts
- Infrastructure security: biometric access control, surveillance, firewall, perimeter network
- Attack types (named as categories): SQL injection, DoS, on-path attacks, brute-force, phishing, ransomware
- Business continuity: DR planning, replication, log shipping, mirroring, RPO/RTO, full/incremental/differential backup, retention policy
