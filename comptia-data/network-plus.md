## Key terminology by domain
- **Concepts**: OSI model layers, TCP/UDP, ports/protocols (FTP, SSH, Telnet, SMTP, DNS, DHCP, HTTP/HTTPS, POP3/IMAP, SNMP, LDAP, SMB, RDP), IPv4/IPv6 addressing and subnetting, routing protocols (OSPF, BGP, RIP, EIGRP), switching concepts (VLAN, STP, trunking), wireless standards (802.11a/b/g/n/ac/ax), cloud concepts (IaaS/PaaS/SaaS, public/private/hybrid)
- **Implementation**: routers, switches, access points, firewalls, load balancers, cabling standards (Cat5e/6/6a, fiber single/multi-mode, SFP/SFP+), wiring distribution (patch panels, punchdown blocks), network topologies, NAT/PAT, VPN
- **Operations**: monitoring tools (SNMP, syslog, NetFlow), documentation (physical/logical network diagrams, wiring diagrams, IPAM), disaster recovery, high availability (NIC teaming, link aggregation, clustering), business continuity, change management, SLAs
- **Security**: network hardening, ACLs, firewall rules, VPNs/IPSec, AAA/RADIUS/TACACS+, physical security, device hardening, common attack types (DoS/DDoS, VLAN hopping, ARP poisoning, rogue DHCP — noted as categories), DMZ, honeypots, zero trust
- **Troubleshooting**: methodology (identify, theorize, test, plan, verify, document), tools (ping, tracert, nslookup/dig, netstat, ipconfig/ifconfig, arp, route, tcpdump), cable testers, wireless troubleshooting (interference, channel overlap, attenuation)
