# Heavy Duty Security Co. — The Enterprise Grid (Concept ENT)

**Archetype:** Ruler &middot; **Visual theme:** Corporate Grid (new — matches live site)

A concept built to match the visual language of HDSC's current live website: a dark navy navigation bar over clean white content, a card-grid of strategic business units, and an authoritative, compliance-forward enterprise tone.

## Contents

- `index.html` — homepage
- `services.html` — full service catalog, rendered from the shared, CompTIA-cited
  catalog in `service-catalog.js`
- `government-contracting.html` — registrations and NAICS/PSC/SIC/UNSPSC
  classification codes, rendered from the shared `govcon-data.js`

## Service catalog

All 13 HDSC brand-concept sites render the **same underlying service catalog**
(see `service-catalog.js` in this repo, sourced from the canonical copy in the
`hdsc-concepts` project). Every service description cites specific, named
technologies, tools, and frameworks verbatim from the relevant CompTIA
certification exam objectives (11 certs: A+ Core 1 & 2, Network+, Security+,
Server+, Cloud+, CySA+, Project+, Data+/AI, DataSys+). Only the presentation —
headline language, tone, and visual skin — differs between concepts; the
underlying technology citations are identical across all 13 sites.
